QuotaScope for Mac

Support

Last updated: June 27, 2026

Need help with QuotaScope? Send a support email with enough detail to reproduce the issue.

Contact

Support email: kibernet@sina.com

What to Include

  • Your macOS version and QuotaScope version.
  • Whether the issue appears in the menu bar app, settings window, or widget.
  • The visible error message or a screenshot with credentials hidden.

Do not send access tokens, refresh tokens, authorization codes, or account passwords.

Common Help

  • If widgets do not update, open QuotaScope, refresh accounts, and re-add the desktop widget.
  • If an account shows a session-ended message, choose Sign in Again from the account menu.
  • If sign-in cannot return to the app, make sure local security software is not blocking localhost callback connections.
  • Use Demo Mode if you only want to inspect the interface without adding a real account.

Privacy

Read the Privacy Policy for details about local storage, Keychain credentials, and network connections.
