Frequently Asked Questions

Why does PanePilot ask for Accessibility permission?

macOS requires Accessibility permission before an app can read window metadata and move or resize windows. PanePilot uses this permission only for window layout actions that you trigger.

Why did a window not move?

Some windows cannot be moved by third-party apps, including full-screen windows, minimized windows, protected system dialogs, and windows from apps that restrict automation. PanePilot avoids these windows to reduce disruption.

How do I arrange multiple windows at once?

Open the control panel, select the windows you want to arrange, choose a preset or custom split layout, then apply the layout to the target display.

How do workspace snapshots work?

A workspace snapshot saves selected window positions and display placement locally on your Mac. You can restore the snapshot later to return to a familiar working setup.

Can I undo a layout action?

Yes. PanePilot records the previous window positions before arrangement so you can undo the last layout action from the app or its global shortcut.

Does PanePilot upload my window titles or app list?

No. PanePilot processes window titles, app names, and window positions locally on your Mac and does not upload them to a server.

What should I include in a support email?

Please include your macOS version, PanePilot version, Mac model, number of displays, the layout or preset used, and screenshots if they help explain the issue.
