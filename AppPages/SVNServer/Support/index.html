Frequently Asked Questions

Does SVNServer Studio include Subversion itself?

SVNServer Studio manages a local Subversion server by using command line tools available on your Mac, including svnserve, svnadmin, svnlook, and svn. If these tools are missing, install Subversion through a trusted package manager such as Homebrew.

Where are repositories stored?

Repositories are stored under the repository root selected in Settings. The default location is inside your home folder under SVNServer Studio/Repositories.

Why can I not connect from another machine?

Check the configured host and port, macOS firewall settings, local network permissions, router rules, and repository authentication. The default host is local to the Mac, which is safer for initial setup.

How do user and group permissions work?

SVNServer Studio writes standard Subversion authentication and authorization files into repository configuration folders. Users, groups, and permission rules are converted into passwd and authz files for svnserve.

How do I back up a repository?

Select a repository and run the hotcopy action. SVNServer Studio uses svnadmin hotcopy to create a local backup in the configured backup folder.

How do I verify repository health?

Select a repository and run verification. SVNServer Studio uses svnadmin verify and records the result in local job history.

Does the app upload repositories or credentials?

No. The current version is local-first and does not upload repositories, backups, users, groups, credentials, or permissions to a developer-operated cloud service.

常见问题解答

SVNServer Studio 是否包含 Subversion 本身？

SVNServer Studio 使用 Mac 上可用的命令行工具（包括svnserve 、 svnadmin 、 svnlook和svn来管理本地 Subversion 服务器。如果缺少这些工具，请通过可信的软件包管理器（例如 Homebrew）安装 Subversion。

存储库存储在哪里？

存储库存储在“设置”中选择的存储库根目录下。默认位置在您的主文件夹下的SVNServer Studio/Repositories中。

为什么我无法从另一台机器连接？

SVNServer Studio 将标准的 Subversion 身份验证和授权文件写入存储库配置文件夹。用户、组和权限规则被转换为svnserve使用的passwd和authz文件。

如何备份存储库？

选择一个存储库并运行热复制操作。SVNServer Studio 使用svnadmin hotcopy在配置的备份文件夹中创建本地备份。

如何验证存储库的健康状况？

选择一个代码库并运行验证。SVNServer Studio 使用svnadmin verify ，并将结果记录在本地作业历史记录中。

该应用是否会上传存储库或凭据？

不。当前版本优先考虑本地部署，不会将存储库、备份、用户、组、凭据或权限上传到开发者运营的云服务。

よくある質問

SVNServer StudioにはSubversion自体が含まれていますか？

SVNServer Studioは、 svnserve 、 svnadmin 、 svnlook 、 svnなど、Macに搭載されているコマンドラインツールを使用してローカルのSubversionサーバーを管理します。これらのツールがインストールされていない場合は、Homebrewなどの信頼できるパッケージマネージャーを使用してSubversionをインストールしてください。

リポジトリはどこに保存されますか？

リポジトリは、設定で選択したリポジトリのルートディレクトリに保存されます。デフォルトの保存場所は、ホームフォルダ内のSVNServer Studio/Repositoriesです。

なぜ他のマシンから接続できないのですか？

設定されているホストとポート、macOSファイアウォールの設定、ローカルネットワークのアクセス許可、ルーターのルール、リポジトリの認証を確認してください。デフォルトのホストはMacのローカルホストであり、初期設定にはより安全です。

ユーザー権限とグループ権限はどのように機能するのですか？

SVNServer Studio は、標準の Subversion 認証および認可ファイルをリポジトリ構成フォルダに書き込みます。ユーザー、グループ、および権限ルールは、 svnserve用のpasswdファイルとauthzファイルに変換されます。

リポジトリをバックアップするにはどうすればよいですか？

リポジトリを選択し、ホットコピーアクションを実行します。SVNServer Studioは、 svnadmin hotcopy使用して、設定されたバックアップフォルダにローカルバックアップを作成します。

リポジトリの健全性を確認するにはどうすればよいですか？

リポジトリを選択して検証を実行します。SVNServer Studioはsvnadmin verifyを使用し、結果をローカルのジョブ履歴に記録します。

アプリはリポジトリや認証情報をアップロードしますか？

いいえ。現在のバージョンはローカル優先であり、リポジトリ、バックアップ、ユーザー、グループ、認証情報、権限を開発者が運用するクラウドサービスにアップロードしません。

Häufig gestellte Fragen

Ist Subversion selbst in SVNServer Studio enthalten?

SVNServer Studio verwaltet einen lokalen Subversion-Server mithilfe von Befehlszeilentools, die auf Ihrem Mac verfügbar sind, darunter svnserve , svnadmin , svnlook und svn . Falls diese Tools fehlen, installieren Sie Subversion über einen vertrauenswürdigen Paketmanager wie Homebrew.

Wo werden die Repositories gespeichert?

Die Repositories werden im Repository-Stammverzeichnis gespeichert, das in den Einstellungen ausgewählt ist. Der Standardspeicherort ist Ihr Home-Verzeichnis unter SVNServer Studio/Repositories .

Warum kann ich mich nicht von einem anderen Rechner aus verbinden?

Überprüfen Sie den konfigurierten Host und Port, die macOS-Firewall-Einstellungen, die Berechtigungen im lokalen Netzwerk, die Router-Regeln und die Repository-Authentifizierung. Der Standardhost ist lokal auf dem Mac, was für die Ersteinrichtung sicherer ist.

Wie funktionieren Benutzer- und Gruppenberechtigungen?

SVNServer Studio schreibt standardmäßige Subversion-Authentifizierungs- und Autorisierungsdateien in die Repository-Konfigurationsordner. Benutzer, Gruppen und Berechtigungsregeln werden in passwd und authz Dateien für svnserve konvertiert.

Wie sichere ich ein Repository?

Wählen Sie ein Repository aus und führen Sie die Hotcopy-Aktion aus. SVNServer Studio verwendet svnadmin hotcopy , um eine lokale Sicherung im konfigurierten Sicherungsordner zu erstellen.

Wie kann ich den Zustand eines Repositorys überprüfen?

Wählen Sie ein Repository aus und führen Sie die Überprüfung durch. SVNServer Studio verwendet dazu svnadmin verify und speichert das Ergebnis im lokalen Auftragsverlauf.

Lädt die App Repositories oder Anmeldeinformationen hoch?

Nein. Die aktuelle Version ist lokal ausgerichtet und lädt keine Repositories, Backups, Benutzer, Gruppen, Anmeldeinformationen oder Berechtigungen in einen vom Entwickler betriebenen Cloud-Dienst hoch.

Preguntas frecuentes

¿SVNServer Studio incluye Subversion?

SVNServer Studio gestiona un servidor Subversion local mediante herramientas de línea de comandos disponibles en tu Mac, como svnserve , svnadmin , svnlook y svn . Si estas herramientas no están disponibles, instala Subversion a través de un gestor de paquetes de confianza como Homebrew.

¿Dónde se almacenan los repositorios?

Los repositorios se almacenan en la raíz del repositorio seleccionada en Configuración. La ubicación predeterminada es dentro de su carpeta de inicio en SVNServer Studio/Repositories .

¿Por qué no puedo conectarme desde otra máquina?

Verifique el host y el puerto configurados, la configuración del firewall de macOS, los permisos de red local, las reglas del enrutador y la autenticación del repositorio. El host predeterminado es local al Mac, lo cual es más seguro para la configuración inicial.

SVNServer Studio escribe archivos de autenticación y autorización estándar de Subversion en las carpetas de configuración del repositorio. Los usuarios, grupos y reglas de permisos se convierten en archivos passwd y authz para svnserve .

¿Cómo hago una copia de seguridad de un repositorio?

Seleccione un repositorio y ejecute la acción hotcopy. SVNServer Studio utiliza svnadmin hotcopy para crear una copia de seguridad local en la carpeta de copias de seguridad configurada.

¿Cómo verifico el estado del repositorio?

Включает ли SVNServer Studio саму систему Subversion?

Где хранятся репозитории?

Репозитории хранятся в корневом каталоге репозиториев, выбранном в настройках. По умолчанию они находятся в вашей домашней папке в SVNServer Studio/Repositories .

Как работают права доступа пользователей и групп?

SVNServer Studio записывает стандартные файлы аутентификации и авторизации Subversion в папки конфигурации репозитория. Пользователи, группы и правила разрешений преобразуются в файлы passwd и authz для svnserve .

Как сделать резервную копию репозитория?

Выберите репозиторий и выполните действие горячего копирования. SVNServer Studio использует svnadmin hotcopy для создания локальной резервной копии в указанной папке резервного копирования.

Repositori disimpan di bawah direktori root repositori yang dipilih di Pengaturan. Lokasi default berada di dalam folder beranda Anda di bawah SVNServer Studio/Repositories .

  • Thao tác bạn đang cố gắng thực hiện, chẳng hạn như tạo kho lưu trữ, khởi động dịch vụ, chỉnh sửa quyền, xác minh kho lưu trữ hoặc tạo bản sao lưu nóng.
  • Bất kỳ thông báo lỗi nào hiển thị, ngoại trừ mật khẩu hoặc nội dung kho lưu trữ riêng tư.

Câu hỏi thường gặp

Liệu SVNServer Studio có bao gồm Subversion hay không?

SVNServer Studio quản lý máy chủ Subversion cục bộ bằng cách sử dụng các công cụ dòng lệnh có sẵn trên máy Mac của bạn, bao gồm svnserve , svnadmin , svnlook và svn . Nếu thiếu các công cụ này, hãy cài đặt Subversion thông qua trình quản lý gói đáng tin cậy như Homebrew.

Các kho lưu trữ được đặt ở đâu?

Các kho lưu trữ được lưu trữ trong thư mục gốc của kho lưu trữ đã chọn trong Cài đặt. Vị trí mặc định là bên trong thư mục chính của bạn, trong SVNServer Studio/Repositories .

Tại sao tôi không thể kết nối từ máy tính khác?

Kiểm tra máy chủ và cổng đã cấu hình, cài đặt tường lửa macOS, quyền truy cập mạng cục bộ, quy tắc bộ định tuyến và xác thực kho lưu trữ. Máy chủ mặc định là máy cục bộ trên máy Mac, điều này an toàn hơn cho quá trình thiết lập ban đầu.

Quyền hạn của người dùng và nhóm hoạt động như thế nào?

SVNServer Studio ghi các tệp xác thực và ủy quyền tiêu chuẩn của Subversion vào các thư mục cấu hình kho lưu trữ. Người dùng, nhóm và quy tắc quyền được chuyển đổi thành các tệp passwd và authz cho svnserve .

Tôi sao lưu kho lưu trữ như thế nào?

Chọn kho lưu trữ và chạy thao tác sao chép nóng (hotcopy). SVNServer Studio sử dụng svnadmin hotcopy để tạo bản sao lưu cục bộ trong thư mục sao lưu đã cấu hình.

Làm thế nào để kiểm tra tình trạng hoạt động của kho lưu trữ?

Chọn kho lưu trữ và chạy xác minh. SVNServer Studio sử dụng svnadmin verify và ghi lại kết quả vào lịch sử công việc cục bộ.

Ứng dụng này có tải lên kho lưu trữ hoặc thông tin đăng nhập không?

Không. Phiên bản hiện tại ưu tiên chạy cục bộ và không tải lên kho lưu trữ, bản sao lưu, người dùng, nhóm, thông tin đăng nhập hoặc quyền hạn lên dịch vụ đám mây do nhà phát triển vận hành.

คำถามที่พบบ่อย

โปรแกรม SVNServer Studio มี Subversion รวมอยู่ด้วยหรือไม่?

SVNServer Studio จัดการเซิร์ฟเวอร์ Subversion ในเครื่องโดยใช้เครื่องมือบรรทัดคำสั่งที่มีอยู่บน Mac ของคุณ ได้แก่ svnserve , svnadmin , svnlook และ svn หากไม่มีเครื่องมือเหล่านี้ ให้ติดตั้ง Subversion ผ่านตัวจัดการแพ็กเกจที่เชื่อถือได้ เช่น Homebrew

ที่เก็บข้อมูลถูกจัดเก็บไว้ที่ใด?

ที่เก็บข้อมูลจะถูกจัดเก็บไว้ในไดเร็กทอรีรากที่เลือกไว้ในการตั้งค่า โดยตำแหน่งเริ่มต้นจะอยู่ในโฟลเดอร์โฮมของคุณ ภายใต้ SVNServer Studio/Repositories

ทำไมฉันถึงเชื่อมต่อจากเครื่องอื่นไม่ได้?

ตรวจสอบการตั้งค่าโฮสต์และพอร์ต การตั้งค่าไฟร์วอลล์ของ macOS สิทธิ์การเข้าถึงเครือข่ายภายใน กฎเราเตอร์ และการตรวจสอบสิทธิ์ของที่เก็บข้อมูล โฮสต์เริ่มต้นจะอยู่ภายในเครื่อง Mac ซึ่งปลอดภัยกว่าสำหรับการตั้งค่าครั้งแรก

การกำหนดสิทธิ์ผู้ใช้และกลุ่มทำงานอย่างไร?

SVNServer Studio จะเขียนไฟล์การตรวจสอบสิทธิ์และการอนุญาตมาตรฐานของ Subversion ลงในโฟลเดอร์การกำหนดค่าของที่เก็บข้อมูล ผู้ใช้ กลุ่ม และกฎการอนุญาตจะถูกแปลงเป็นไฟล์ passwd และ authz สำหรับ svnserve

ฉันจะสำรองข้อมูลที่เก็บข้อมูลได้อย่างไร?

เลือกแหล่งเก็บข้อมูลและเรียกใช้คำสั่ง hotcopy SVNServer Studio ใช้ svnadmin hotcopy เพื่อสร้างสำเนาสำรองในเครื่องในโฟลเดอร์สำรองข้อมูลที่กำหนดค่าไว้

ฉันจะตรวจสอบความสมบูรณ์ของที่เก็บข้อมูลได้อย่างไร?

เลือกแหล่งเก็บข้อมูลและเรียกใช้การตรวจสอบ SVNServer Studio ใช้ svnadmin verify และบันทึกผลลัพธ์ลงในประวัติงานในเครื่อง

แอปนี้อัปโหลดที่เก็บข้อมูลหรือข้อมูลรับรองหรือไม่?

ไม่ เวอร์ชันปัจจุบันเน้นการใช้งานในเครื่องเป็นหลัก และจะไม่ทำการอัปโหลดที่เก็บข้อมูล ข้อมูลสำรอง ผู้ใช้ กลุ่ม ข้อมูลประจำตัว หรือสิทธิ์การเข้าถึงไปยังบริการคลาวด์ที่ดำเนินการโดยนักพัฒนา
