SVNServer Studio for Mac

Privacy Policy

Last updated: May 27, 2026

SVNServer Studio is a local-first Subversion server manager for Mac. It helps users create and manage local SVN repositories, start or stop a local svnserve service, manage SVN users and groups, configure repository permissions, run verification and backup jobs, and review local activity logs.

Summary: SVNServer Studio does not collect personal data, does not require an account, does not include advertising SDKs, and does not include third-party tracking SDKs. App data is stored locally on your Mac to provide the app's core server-management features.

Data We Collect

SVNServer Studio does not collect personal data in the current version. The app does not operate a cloud account service, does not upload your repository data to a developer-controlled server, and does not sell, share, or track personal information.

Data Stored Locally on Your Mac

To provide its core features, SVNServer Studio stores configuration and operational data locally. This may include:

  • Repository root path, backup path, host, port, auto-start preference, language preference, and layout settings.
  • Repository names, descriptions, file paths, UUIDs, revision information, size information, verification history, and backup history.
  • SVN user names, display names, account status, group membership, permission rules, and SVN password entries used to generate Subversion authentication files.
  • Local job records and activity logs, such as repository creation, verification, hotcopy backup, service start or stop, and configuration updates.

This data is stored in the user's Mac account and in the repository folders selected by the user. SVNServer Studio uses this local data to generate standard Subversion files such as svnserve.conf, passwd, and authz.

Repository Content

SVN repositories and backups are stored in locations chosen by the user. Repository files, commits, imported assets, source code, and backup copies remain under the user's control on the Mac or storage locations selected by the user. SVNServer Studio does not upload repository content to a developer-operated service.

Network Access

SVNServer Studio can start a local svnserve process using the host and port configured by the user. The default host is local to the Mac. If the user changes the host, firewall, network, or router configuration to expose the SVN service to a local network or the Internet, the user is responsible for access control, credential strength, repository permissions, and network security.

Passwords and Credentials

SVNServer Studio manages SVN password entries for the local Subversion service. These credentials are used to generate Subversion authentication files inside repository configuration folders. Treat your Mac user account, app support folder, repository folders, and backup folders as sensitive locations. Use strong passwords and restrict file-system access to trusted administrators.

Third-Party Services

The current version does not include analytics, advertising networks, third-party tracking SDKs, cloud synchronization, crash-reporting SDKs, payment SDKs, or social sign-in. The app uses command line tools installed on the Mac, such as svnserve, svnadmin, svnlook, and svn, when available.

Data Deletion

You can delete repositories, backups, exported files, and local app state from the locations where they are stored. Removing local SVN users, groups, permission rules, repositories, backups, or the app support data from your Mac removes those local records from your device. SVNServer Studio does not maintain a remote account or server-side user profile.

Children's Privacy

SVNServer Studio is a developer and server administration utility. It is not directed to children and does not knowingly collect information from children or any other users.

Changes to This Policy

If this policy changes, the updated version will be posted on this page with a revised update date. If future versions add optional cloud features, analytics, crash reporting, subscriptions, or server-side processing, this policy and App Store privacy declarations will be updated before release.

SVNServer Studio adalah pengelola server Subversion berbasis lokal untuk Mac. Untuk menyediakan fitur-fitur intinya, SVNServer Studio menyimpan data konfigurasi dan operasional secara lokal. Ini mungkin termasuk:

  • Jalur root repositori, jalur cadangan, host, port, preferensi mulai otomatis, preferensi bahasa, dan pengaturan tata letak.

Kata Sandi dan Kredensial

SVNServer Studio mengelola entri kata sandi SVN untuk layanan Subversion lokal. Kredensial ini digunakan untuk menghasilkan file otentikasi Subversion di dalam folder konfigurasi repositori. Perlakukan akun pengguna Mac Anda, folder dukungan aplikasi, folder repositori, dan folder cadangan sebagai lokasi sensitif. Gunakan kata sandi yang kuat dan batasi akses sistem file hanya untuk administrator tepercaya.

นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 27 พฤษภาคม 2569

SVNServer Studio เป็นโปรแกรมจัดการเซิร์ฟเวอร์ Subversion สำหรับ Mac ที่เน้นการใช้งานในเครื่องเป็นหลัก ช่วยให้ผู้ใช้สร้างและจัดการที่เก็บข้อมูล SVN ในเครื่อง เริ่มหรือหยุดบริการ svnserve ในเครื่อง จัดการผู้ใช้และกลุ่ม SVN กำหนดค่าสิทธิ์การเข้าถึงที่เก็บข้อมูล เรียกใช้การตรวจสอบและสำรองข้อมูล และตรวจสอบบันทึกกิจกรรมในเครื่อง

สรุป: SVNServer Studio ไม่เก็บรวบรวมข้อมูลส่วนบุคคล ไม่จำเป็นต้องมีบัญชีผู้ใช้ ไม่รวม SDK สำหรับโฆษณา และไม่รวม SDK สำหรับการติดตามจากบุคคลที่สาม ข้อมูลแอปจะถูกจัดเก็บไว้ในเครื่อง Mac ของคุณ เพื่อให้แอปสามารถทำงานด้านการจัดการเซิร์ฟเวอร์หลักได้

ข้อมูลที่เราเก็บรวบรวม

SVNServer Studio เวอร์ชันปัจจุบันไม่เก็บรวบรวมข้อมูลส่วนบุคคล แอปพลิเคชันนี้ไม่มีบริการบัญชีคลาวด์ ไม่ทำการอัปโหลดข้อมูลคลังเก็บข้อมูลของคุณไปยังเซิร์ฟเวอร์ที่ควบคุมโดยนักพัฒนา และไม่ขาย แบ่งปัน หรือติดตามข้อมูลส่วนบุคคล

ข้อมูลที่จัดเก็บไว้ในเครื่อง Mac ของคุณ

เพื่อให้สามารถใช้งานฟังก์ชันหลักได้ SVNServer Studio จะจัดเก็บข้อมูลการกำหนดค่าและข้อมูลการดำเนินงานไว้ในเครื่อง ซึ่งอาจรวมถึง:

  • เส้นทางรากของที่เก็บข้อมูล เส้นทางสำรองข้อมูล โฮสต์ พอร์ต การตั้งค่าการเริ่มต้นอัตโนมัติ การตั้งค่าภาษา และการตั้งค่าเค้าโครง
  • ชื่อของแหล่งเก็บข้อมูล คำอธิบาย เส้นทางไฟล์ UUID ข้อมูลการแก้ไข ข้อมูลขนาด ประวัติการตรวจสอบ และประวัติการสำรองข้อมูล
  • ชื่อผู้ใช้ SVN, ชื่อที่แสดง, สถานะบัญชี, การเป็นสมาชิกกลุ่ม, กฎการอนุญาต และรายการรหัสผ่าน SVN ที่ใช้ในการสร้างไฟล์การตรวจสอบสิทธิ์ Subversion
  • บันทึกงานและบันทึกกิจกรรมในเครื่อง เช่น การสร้างที่เก็บข้อมูล การตรวจสอบ การสำรองข้อมูลแบบ hotcopy การเริ่มต้นหรือหยุดบริการ และการอัปเดตการกำหนดค่า

ข้อมูลนี้จะถูกจัดเก็บไว้ในบัญชี Mac ของผู้ใช้และในโฟลเดอร์เก็บข้อมูลที่ผู้ใช้เลือกไว้ SVNServer Studio ใช้ข้อมูลในเครื่องนี้เพื่อสร้างไฟล์ Subversion มาตรฐาน เช่น svnserve.conf , passwd และ authz

เนื้อหาคลังข้อมูล

ที่เก็บข้อมูลและสำเนาสำรองของ SVN จะถูกจัดเก็บไว้ในตำแหน่งที่ผู้ใช้เลือก ไฟล์ในที่เก็บข้อมูล การเปลี่ยนแปลงข้อมูล ทรัพย์สินที่นำเข้า ซอร์สโค้ด และสำเนาสำรองยังคงอยู่ภายใต้การควบคุมของผู้ใช้บน Mac หรือตำแหน่งจัดเก็บข้อมูลที่ผู้ใช้เลือก SVNServer Studio ไม่ได้อัปโหลดเนื้อหาในที่เก็บข้อมูลไปยังบริการที่ดำเนินการโดยนักพัฒนา

การเข้าถึงเครือข่าย

SVNServer Studio สามารถเริ่มต้นกระบวนการ svnserve ในเครื่องโลคอลได้โดยใช้โฮสต์และพอร์ตที่ผู้ใช้กำหนดค่าไว้ โฮสต์เริ่มต้นคือเครื่อง Mac เอง หากผู้ใช้เปลี่ยนโฮสต์ ไฟร์วอลล์ เครือข่าย หรือการกำหนดค่าเราเตอร์เพื่อเปิดเผยบริการ SVN ไปยังเครือข่ายภายในหรืออินเทอร์เน็ต ผู้ใช้จะต้องรับผิดชอบในการควบคุมการเข้าถึง ความแข็งแกร่งของข้อมูลประจำตัว สิทธิ์การเข้าถึงที่เก็บข้อมูล และความปลอดภัยของเครือข่าย

รหัสผ่านและข้อมูลประจำตัว

SVNServer Studio จัดการรายการรหัสผ่าน SVN สำหรับบริการ Subversion ในเครื่อง ข้อมูลประจำตัวเหล่านี้ใช้ในการสร้างไฟล์การตรวจสอบสิทธิ์ Subversion ภายในโฟลเดอร์การกำหนดค่าของที่เก็บข้อมูล โปรดถือว่าบัญชีผู้ใช้ Mac โฟลเดอร์สนับสนุนแอป โฟลเดอร์ที่เก็บข้อมูล และโฟลเดอร์สำรองข้อมูลเป็นสถานที่สำคัญ ใช้รหัสผ่านที่รัดกุมและจำกัดการเข้าถึงระบบไฟล์เฉพาะผู้ดูแลระบบที่น่าเชื่อถือเท่านั้น

บริการจากบุคคลที่สาม

เวอร์ชันปัจจุบันไม่รวมการวิเคราะห์ข้อมูล เครือข่ายโฆษณา SDK ติดตามข้อมูลจากบุคคลที่สาม การซิงโครไนซ์ข้อมูลบนคลาวด์ SDK รายงานข้อผิดพลาด SDK การชำระเงิน หรือการลงชื่อเข้าใช้ผ่านโซเชียล แอปใช้เครื่องมือบรรทัดคำสั่งที่ติดตั้งบน Mac เช่น svnserve , svnadmin , svnlook และ svn เมื่อมีให้ใช้งาน

การลบข้อมูล

คุณสามารถลบที่เก็บข้อมูล ข้อมูลสำรอง ไฟล์ที่ส่งออก และสถานะแอปในเครื่องจากตำแหน่งที่จัดเก็บได้ การลบผู้ใช้ SVN กลุ่ม กฎการอนุญาต ที่เก็บข้อมูล ข้อมูลสำรอง หรือข้อมูลสนับสนุนแอปในเครื่อง Mac ของคุณ จะลบข้อมูลเหล่านั้นออกจากอุปกรณ์ของคุณด้วย SVNServer Studio ไม่ได้เก็บรักษาบัญชีระยะไกลหรือโปรไฟล์ผู้ใช้ฝั่งเซิร์ฟเวอร์

ความเป็นส่วนตัวของเด็ก

SVNServer Studio เป็นยูทิลิตี้สำหรับนักพัฒนาและบริหารจัดการเซิร์ฟเวอร์ ไม่ได้มีไว้สำหรับเด็ก และไม่ได้เก็บรวบรวมข้อมูลจากเด็กหรือผู้ใช้รายอื่นโดยเจตนา

การเปลี่ยนแปลงนโยบายนี้

หากนโยบายนี้มีการเปลี่ยนแปลง เวอร์ชันที่อัปเดตแล้วจะถูกโพสต์บนหน้านี้พร้อมวันที่อัปเดตที่แก้ไขแล้ว หากเวอร์ชันในอนาคตเพิ่มคุณสมบัติคลาวด์เสริม การวิเคราะห์ การรายงานข้อผิดพลาด การสมัครสมาชิก หรือการประมวลผลฝั่งเซิร์ฟเวอร์ นโยบายนี้และประกาศความเป็นส่วนตัวของ App Store จะได้รับการอัปเดตก่อนการเผยแพร่
