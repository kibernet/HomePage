SVNServer Studio for Mac

Age Rating Information

Last updated: May 27, 2026

SVNServer Studio is a developer tool and local Subversion server manager for Mac. It is intended for general audiences who need to create repositories, manage users and groups, configure permissions, run local verification and backup jobs, and control a local SVN service.

Recommended App Store Age Rating: 4+
