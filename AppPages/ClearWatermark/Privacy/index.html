ClearWatermark for iPhone, iPad, and Mac

Privacy Policy

Last updated: May 27, 2026

ClearWatermark is a local AI image repair and inpainting app. It helps users edit images they own or have permission to modify by brushing over an area, processing the image on device, and exporting the result.

Data We Collect

ClearWatermark does not collect personal data in the current version. The app does not require sign-in, does not operate a cloud account service, does not include advertising SDKs, and does not include third-party tracking SDKs.

Images and Editing Data

Images selected by the user, masks, brush strokes, and edited results are processed locally on the user's device. ClearWatermark does not upload selected images, masks, or edited results to a server or third-party AI service.

Photos and File Access

  • On iPhone and iPad, Photos access is used only when the user chooses an image or saves an edited result.
  • On Mac, file access is limited to files the user explicitly selects through the system file picker, drag and drop, or export panel.

On-Device Model Processing

ClearWatermark uses a bundled Core ML inpainting model for local image repair. The current version does not send image content to remote AI services.

Analytics, Diagnostics, and Tracking

The current version does not collect analytics, crash logs, advertising identifiers, tracking identifiers, location data, contact information, account information, or usage history.

Data Deletion

ClearWatermark does not maintain a remote account or server-side user record. Imported images and exported files remain under the user's control in the locations selected by the user. Users can delete exported files from their device at any time.

Children's Privacy

ClearWatermark is a general photo editing utility and is not directed to children. The app does not knowingly collect information from children or any other users.

Changes to This Policy

If this policy changes, the updated version will be posted on this page with a revised update date. If future versions add optional cloud features, analytics, crash reporting, account sync, subscriptions, or server-side processing, this policy and App Store privacy declarations will be updated before release.
