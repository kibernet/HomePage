Support Diagnostics

In ScreenSplitAssist, open Support & Policies and choose Copy Diagnostics before emailing support. The report uses stable English labels and includes release-safe state, install-location and code-signature categories, Accessibility identity risk, plus last-run counts without window titles, managed app names, document names, template names, workspace names, or full local paths.

  • Version, Build, macOS, and Architecture
  • App Location, Stable Install Location, Code Signature, and Signing Team
  • Accessibility Identity Risk, Accessibility Trusted, Privacy Scope, Displays, Selected Preset, Selected Category, and Last Run
