CineCapturePro for macOS

隐私政策

最后更新：2026 年 6 月 21 日

CineCapturePro 是一款面向 macOS 的本地优先录制工作室，用于屏幕录制、窗口和 App 采集、系统声音、麦克风、摄像头画中画、录制素材库、字幕草稿、章节、导出和工作区归档。

摘要：CineCapturePro 不需要账号，不包含广告 SDK，不包含第三方追踪 SDK，也不会把你的录制内容上传到开发者运营的服务器。录制、导出、缩略图、字幕和素材库数据默认保存在你的 Mac 本地。

本地优先录制和素材库保存在你的 Mac 上。
无追踪不用于广告追踪或跨 App 追踪。
无默认云上传不会自动上传录制内容。

我们收集的数据

当前版本的 CineCapturePro 不会通过开发者运营的在线服务收集、上传、出售或共享个人数据。应用不提供开发者账号系统、云同步、广告、第三方分析、崩溃上报 SDK 或第三方追踪 SDK。

保存在 Mac 本地的数据

为了提供核心录制和后期工作流，CineCapturePro 可能在你的 Mac 本地保存或处理以下数据：

  • 录制设置、预设、语言、主题、输出文件夹、安全作用域书签和窗口状态。
  • 录制视频、音频轨道、系统声音、麦克风音频、摄像头画面和画中画合成结果。
  • 录制素材库记录、缩略图、标签、文件大小、时长、编码格式、分辨率、帧率、HDR 状态和 sidecar JSON 元数据。
  • 用户创建或导出的字幕草稿、章节、回看笔记、导出记录、诊断报告和工作区归档。
  • 本地工作流配置文件或插件清单。当前版本只把这些文件作为本地 JSON 元数据读取，不加载可执行插件代码。
  • 录制恢复标记，用于在异常退出后提示用户处理未完成的录制。

这些数据用于在你的设备上提供录制、管理、恢复和导出功能。除非你主动通过 Finder、邮件、浏览器、云盘或其他工具分享这些文件，否则它们不会发送给我们。

系统权限

CineCapturePro 只在你使用相关功能时请求 Apple 系统权限：

  • Screen Recording：用于采集显示器、窗口、App、区域录制和系统声音相关工作流。
  • Microphone：用于录制旁白、麦克风音轨、音频电平和多音轨录制。
  • Camera：用于摄像头预览、摄像头录制和画中画叠加。
  • Input Monitoring：用于全局快捷键、键盘操作监听和按键叠加显示。
  • Files and Folders：用于访问你选择的输出目录、录制文件、导出目标和工作区归档位置。

授予这些权限不会把你的屏幕、摄像头、麦克风、键盘输入或文件内容发送给开发者。你可以在 macOS 系统设置中撤销这些权限。

录制内容和导出

录制文件、音频轨道、缩略图、字幕、导出文件和归档文件会保存到你选择的位置，或保存到 macOS 提供的本地文件夹，例如 Movies 文件夹。CineCapturePro 不会自动上传这些内容，也不会通过开发者服务器代理这些内容。

诊断、性能和 Required Reason API

应用会在本地读取必要的系统信息来完成录制准备检查和性能显示，例如可用磁盘空间、文件时间戳、应用偏好、录制计时和预览节流。这些用途与应用的 PrivacyInfo.xcprivacy 隐私清单一致，仅用于本地功能，不用于追踪。

字幕、笔记和未来在线功能

当前版本的字幕草稿、章节、摘要、回看笔记和工作区归档按本地文件处理。若未来版本增加可选的在线 AI、转写、云同步、团队协作或上传服务，我们会在发布前更新本政策、App Store 隐私声明和应用内说明，并在功能使用前清楚告知用户。

支持请求

如果你通过邮件联系我们获取支持，我们会收到你主动提供的信息，例如邮箱地址、问题描述、截图、日志或诊断详情。请不要发送密码、私人密钥、敏感录制内容、机密屏幕截图或不希望我们查看的文件。支持信息仅用于回复你的请求。

第三方服务和用户主动分享

当前版本不包含广告网络、第三方分析 SDK、社交登录、支付 SDK、云同步或远程工作流服务。若你把录制文件、导出文件或诊断信息保存到第三方云盘、发送给他人、上传到网站或导入其他 App，该处理行为受你选择的第三方服务或工具的政策约束。

数据删除和保留

你可以在 CineCapturePro 中移除素材库记录，也可以在 Finder 中删除录制文件、sidecar JSON、缩略图、字幕、导出文件、工作区归档和本地工作流配置。卸载应用会移除应用本体，但用户保存到输出文件夹或其他位置的录制和导出文件会保留，直到你自行删除。

儿童隐私

CineCapturePro 是面向创作者、教育、产品演示和专业录制工作流的生产力工具，不面向儿童。应用不会 knowingly 收集儿童或任何其他用户的信息。

政策变更

如果本政策发生变更，更新后的版本会发布在本页面，并更新日期。如果未来功能改变数据处理方式，我们会在提交相应版本前更新本政策和 App Store Connect 隐私信息。
