Frequently Asked Questions

Does SpaceManagerPro upload my workspace data?

No. SpaceManagerPro is local-first. Workspace profiles, display mappings, hotkeys, settings, and window layout snapshots are stored on your Mac.

Why does SpaceManagerPro ask for Accessibility permission?

Accessibility permission is used for desktop switching commands and optional window layout features. If switching or layout restore does not work, confirm that SpaceManagerPro is enabled in System Settings > Privacy & Security > Accessibility.

Can SpaceManagerPro rename native Mission Control desktops?

No. macOS does not provide a public API for renaming native Mission Control desktops. SpaceManagerPro provides an app-level workspace profile layer with names, icons, colors, notes, and hotkeys.

Why does a global shortcut not work?

If another app or macOS feature already uses the same shortcut, SpaceManagerPro may not be able to register it. Choose a different shortcut in the app settings or remove the conflicting shortcut from the other app.

How do I back up my configuration?

Use the configuration export feature in SpaceManagerPro to create a local backup file. You can import that file later to restore your workspace profiles and settings.

How do window layout snapshots work?

When you explicitly save a layout snapshot, SpaceManagerPro records visible window information such as app names, window titles, frame positions, and sizes. The snapshot is stored locally and is used only when you choose to restore that layout.
